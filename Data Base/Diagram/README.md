# Diagram

## Descripción

La carpeta `Diagram` contiene los recursos utilizados para documentar visualmente la arquitectura de la base de datos **VitalMind AI**.

Estos archivos sirven como referencia para comprender las entidades, relaciones, atributos y organización general del modelo de datos.

## Archivos

### `MySQL Workbench Models VitalMind.mwb`

Archivo de modelo de **MySQL Workbench**.

Permite consultar y modificar el modelo visual de la base de datos, incluyendo las relaciones entre las diferentes entidades.

### `DIccionario de datos VitalMind.html`

Documento HTML que contiene el diccionario de datos de VitalMind.

Permite consultar información relacionada con las tablas y campos que conforman la base de datos.

## Uso recomendado

El modelo debe utilizarse como referencia antes de modificar tablas, relaciones o campos existentes.

El diccionario de datos permite identificar el propósito y las características de los elementos de la base de datos antes de realizar cambios en los scripts SQL.
