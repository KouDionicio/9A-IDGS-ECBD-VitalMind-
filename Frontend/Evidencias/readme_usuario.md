## 📌 Descripción

**VitalMind AI** es una plataforma web enfocada en el seguimiento integral de la salud y el bienestar. Su interfaz permite al usuario registrar información diaria, consultar tendencias, visualizar indicadores, recibir recomendaciones personalizadas y utilizar un asistente conversacional.

El sistema está diseñado alrededor de una experiencia clara, visual y responsiva, con módulos independientes que se integran en un mismo flujo de usuario.

---

## ✨ Funcionalidades principales

| Módulo | Descripción |
|---|---|
| 🔐 **Autenticación** | Inicio de sesión y acceso seguro a la plataforma. |
| 🏠 **Dashboard** | Vista general del estado de bienestar y resumen diario. |
| 📝 **Registro de síntomas** | Captura de dolor, temperatura, frecuencia cardiaca, presión, glucosa, peso y estado emocional. |
| 📊 **Resumen y gráficas** | Seguimiento de bienestar, evolución emocional, síntomas y actividad. |
| 🤖 **Recomendaciones IA** | Insights personalizados y alertas preventivas basadas en los registros. |
| 💬 **VitalMind Chat** | Asistente conversacional para consultas relacionadas con bienestar y hábitos. |
| 📅 **Citas médicas** | Gestión de próximas citas e historial de consultas. |
| 💊 **Medicamentos** | Control de horarios, dosis, adherencia y seguimiento del tratamiento. |
| 🩺 **Historial médico** | Consulta de enfermedades, alergias, medicamentos, cirugías, consultas, vacunas y resultados clínicos. |
| 👤 **Perfil** | Métricas, metas, logros y configuración personal. |
| 🔔 **Notificaciones** | Recomendaciones y avisos personalizados. |
| 🌙 **Modo oscuro** | Alternativa visual para una experiencia más cómoda. |

## 🛠️ Interfaces del sistema

VitalMind AI se divide en dos experiencias principales:

### 👤 Interfaz del usuario
Es la interfaz documentada en este README. Está orientada al paciente/usuario final e incluye:

- Dashboard de bienestar.
- Registro de síntomas y signos vitales.
- Hábitos saludables.
- Gráficas y seguimiento.
- Recomendaciones mediante IA.
- Chatbot inteligente.
- Historial médico.
- Medicamentos y adherencia al tratamiento.
- Citas médicas.
- Notificaciones.
- Perfil, metas y logros.
- Modo claro y modo oscuro.

### 🛡️ Interfaz administrativa
La plataforma también cuenta con un **panel administrativo** destinado a la gestión y supervisión del sistema.

> La interfaz administrativa ya cuenta con evidencias visuales y se documenta en la sección **Interfaz administrativa**.

## 🎨 Diseño de interfaz

VitalMind AI utiliza una identidad visual orientada al sector salud y bienestar, combinando:

- **Gradientes turquesa y azul** para transmitir confianza y tecnología.
- **Tarjetas y paneles** para organizar información compleja de manera sencilla.
- **Indicadores visuales** para facilitar la interpretación de métricas.
- **Iconografía contextual** para síntomas, hábitos, actividad y bienestar.
- **Diseño responsivo** orientado a una experiencia web moderna.
