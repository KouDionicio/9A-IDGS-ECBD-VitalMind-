## 🩺 Sobre VitalMind

**VitalMind** es un proyecto enfocado en el desarrollo de una plataforma para la gestión y consulta de información relacionada con la salud.

El sistema cuenta con una arquitectura basada en tecnologías como:

* **Node.js**
* **Express.js**
* **MySQL**
* **REST API**
