# Librerías del Backend

Esta sección contiene las principales librerías utilizadas en el backend de **VitalMind**, necesarias para desarrollar, ejecutar y mantener la API.

## 📚 Principales librerías

| Librería    | Función                                                      |
| ----------- | ------------------------------------------------------------ |
| **Express** | Creación y manejo del servidor y las rutas de la API.        |
| **MySQL2**  | Conexión y consultas a la base de datos MySQL.               |
| **dotenv**  | Manejo de variables de entorno y configuración del proyecto. |
| **CORS**    | Permite la comunicación entre el frontend y backend.         |
| **Nodemon** | Reinicia automáticamente el servidor durante el desarrollo.  |

## ⚙️ Instalación

Las dependencias se instalan mediante:

```bash
npm install
```

Para instalar las principales librerías:

```bash
npm install express mysql2 dotenv cors
```

Para desarrollo:

```bash
npm install --save-dev nodemon
```

## 📦 package.json

Las librerías instaladas se registran en el archivo `package.json`, permitiendo administrar las dependencias necesarias para ejecutar el backend.

## 🛠️ Tecnologías

* Node.js
* Express.js
* MySQL
* JavaScript
* npm

## 📌 Objetivo

Las librerías permiten construir una API REST funcional, conectar el backend con MySQL, manejar solicitudes HTTP, configurar variables de entorno y facilitar el desarrollo del proyecto.
